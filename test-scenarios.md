Home Credit LAP Voice Agent — Test Scenarios

Test 1: Eligible Customer

Input: Customer has a residential property, ownership is acceptable, original documents are available, requests ₹50 lakh, is salaried with income received in a bank account, and requests a 10-year tenure.

Expected result: The agent collects the required details and confirms eligibility for a senior expert callback, subject to the stated qualification rules.

Test 2: Agricultural Property

Input: Customer wants a loan against agricultural property.

Expected result: The agent politely explains that the property does not meet the eligibility criteria.

Test 3: Original Documents Unavailable

Input: Customer does not have the original property documents.

Expected result: The agent explains that original documents are required.

Test 4: Loan Amount Above ₹75 Lakh

Input: Customer requests ₹90 lakh.

Expected result: The agent explains that the maximum loan amount under these rules is ₹75 lakh and asks whether the customer would like to proceed with that amount.

Test 5: Cash Income

Input: Customer is self-employed but receives income only in cash.

Expected result: The agent explains that income received through a bank account is required.

Test 6: Existing Loan on Property

Input: Customer already has a loan against the property or wants to reduce the EMI.

Expected result: The agent routes the customer to a loan-transfer specialist.

Test 7: Invalid Tenure

Input: Customer requests a tenure of 2 years or 20 years.

Expected result: The agent explains that the permitted tenure is 3–15 years.

Test 8: Customer Answers Out of Order

Input: Customer gives several eligibility details in a different order from the agent's questions.

Expected result: The agent remembers the details already provided and asks only for missing information.

Test 9: Diversion

Input: Customer asks an unrelated question during qualification.

Expected result: The agent responds briefly where appropriate and politely returns to the qualification conversation.
