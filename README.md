Home Credit Loan Against Property Voice Agent

Project Overview

This project is a voice agent designed to qualify customers interested in a Home Credit Loan Against Property (LAP).

Objectives

- Collect customer eligibility details through a natural conversation.
- Check property type, ownership, original documents, loan amount, occupation, income source, property value, and loan tenure.
- Identify ineligible customers based on the qualification rules.
- Route existing property-loan or EMI-reduction requests to a loan-transfer specialist.
- Arrange a callback from a senior expert for eligible customers.

Technology

- Voice AI platform: Retell AI (or the platform used for the final agent)
- System prompt: Custom instructions for customer qualification

Testing

The agent is tested using eligible, ineligible, and loan-transfer scenarios. Actual test results and call recordings should be added after testing.
